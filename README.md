# HabitTracker

HabitTracker — это API для создания, зранения, обработки полезных привычек. Интегрирация с Telegram позволяет ему
автомотически напоминать пользователю о необходимости выполнить привычки. Эта программа сделана по мотивам книги Джеймса
Клира «Атомарные привычки».

## Установка

1. Клонируйте данный репозиторий командой:

```
git clone https://github.com/a-babushkin/Habit-Tracker.git
```

2. Установка зависимостей проекта:

```
poetry intall
```

3. Запустите локальный сервер командой:

```
 python manage.py runserver
```

4. Административная панель для управления сущностями проекта находится по адресу:

```
 http://127.0.0.1:8000/admin/
```

5. Документация API по эндпоинтам проекта находится по адресу:

```
http://127.0.0.1:8000/swagger/
```
